# Changelog

All notable user-visible changes to the Stirling PDF TOS application package.

## 3.3.0-1 — 2026-11-09

### Added
- First release. Stirling PDF (`stirlingtools/stirling-pdf:3.3.0`, Docker Hub official image, unmodified)
  packaged as a TOS 7 Docker application, published on port 8028 and running
  as a non-root user (1000:1000).
- Persistent data is kept under `/Volume1/DockerAppData/stirlingpdfdocker/`.
